# Mid-State Shuttle Service

Capstone project developed for Mid-State Technical College to modernize and streamline shuttle transportation management.

---

## Features

- Student shuttle request registration
- Route and schedule management
- Rider and driver administration
- Excel-based route uploads
- CSV report exports
- Mail/package tracking
- Role-based authentication with Azure AD
- Azure cloud deployment and logging

---

## Technologies Used

- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap
- JavaScript
- Azure App Service
- Azure Application Insights
- GitHub Actions
- xUnit

---

## Roles

| Role | Access |
|---|---|
| Rider | Submit shuttle requests |
| Driver | View assigned routes and track mail |
| Admin | Full management access |

---

## Configuration

The application uses:

- SQL Server connection strings
- Azure Active Directory authentication
- Azure App Service deployment settings
- Application Insights logging configuration

---

## Testing

Includes unit and integration testing using xUnit and ASP.NET Core testing tools.
