# Campus Shuttle Service

## Overview
The Campus Shuttle Service project is a web-based transportation management system designed to simplify shuttle operations for students, drivers, and administrators. The application provides an organized platform for submitting ride requests, managing routes, scheduling transportation, and generating reports.

The goal of the project is to improve transportation accessibility, reduce manual scheduling processes, and create a more efficient and user-friendly experience for everyone involved.

---

## Features

- Student shuttle request submission
- Route and schedule management
- Driver and administrator dashboards
- Role-based authentication and authorization
- Excel route upload functionality
- CSV report exporting
- Administrative reporting tools
- Mail tracking system
- Azure AD authentication
- Responsive web interface

## User Roles

### Rider
- Submit transportation requests
- View available routes and schedules

### Driver
- Access assigned routes
- Manage transportation-related tasks

### Administrator
- Manage routes and schedules
- Upload route data through Excel
- Generate reports and exports
- Access administrative tools and dashboards
